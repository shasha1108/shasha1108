02 / THREE FLAGSHIPS

Not showpieces: three interaction causalities.

Each work answers the same five questions: what it holds, what you must do, how the system decides, how the world responds, and why it must work this way.

01 / instrument

Eternal Bloom

  1. 01What it holds

    It holds the suspension of “I am afraid it will disappear”: a bloom is allowed to continue rather than being rushed into a single explanation.

  2. 02What the visitor must do

    The visitor must tune the flower's colour, form, or rhythm first, rather than receiving comfort already completed for them.

  3. 03How the system decides

    The system reads only explicit parameters and touch. It does not infer an emotion or name the flower for a person.

  4. 04How the world responds

    Parameters and touch alter the bloom while sound arrives with it. The response is visible without demanding an account.

  5. 05Why this interaction must be this way

    Only a small, deliberate choice makes the bell jar's continuing bloom care left by the visitor, rather than automated background animation.

02 / instrument

BOTTLED COSMOS

  1. 01What it holds

    It holds the immensity and brevity of “there is too much to see”: every star lives for thirty seconds, yet can rest in a bottle.

  2. 02What the visitor must do

    The visitor must choose when to approach and open the bottle. The homepage does not run a cosmos in the background for anyone.

  3. 03How the system decides

    The system treats that explicit entry as its only start condition, then gives stars a finite interval to appear, change, and go dark.

  4. 04How the world responds

    After entry, the stars run within their thirty seconds. The glass boundary makes an immense scale feel holdable.

  5. 05Why this interaction must be this way

    A cosmos must be opened by a person so brevity is not attention taken by an algorithm, but time deliberately chosen.

03 / instrument

Layered Mountains

  1. 01What it holds

    It holds moments that neither want to be fixed nor called lost: scattering is not loss, and gathering is not an obligation to stay.

  2. 02What the visitor must do

    The visitor must rest a gaze or pointer on the ridges. No personal account is required, only a willingness to stay.

  3. 03How the system decides

    The system uses the relation between raycasting and the particle landscape to decide local disturbance; it infers no psychological state from a visitor.

  4. 04How the world responds

    Blue-green ridges loosen, appear, and gather anew in local relation. The reply is a mountain seen differently, not a popup.

  5. 05Why this interaction must be this way

    Only an approach that changes the act of seeing preserves room for things to gather and scatter; turning it into a reward click would remove that room.

Keep decision-making human.

  2. 02I do not write a completed publication as proof that growth happened.

  4. 04I do not let a formula replace a real reader goal.
